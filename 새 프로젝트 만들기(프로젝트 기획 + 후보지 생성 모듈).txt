**새 프로젝트 만들기(프로젝트 기획 + 후보지 생성 모듈) 
1. 새 프로젝트 만들기 버튼 클릭
2. 유저 입력 받기
 - 유저의 정체성 : (예: 미국의 여행 유튜버)
 - 장소 : (예 : 너무 디테일 한 곳 아니어도 최소 지역은 정해야함. 춘천 등)
     - 지도 이미지 띄우고 지역별 특징 설명하는 ui(각 지역별 1월에서 12월 볼거리 등 간단 요약)
 - 날짜 : date
 - 인원 : 
  - 몇명 : 
    - 인원 : R&R (예 : 감독, 출연자 등)
 -유저 지메일 연동(구글)
 - 컨셉 : 후보 장소 프롬프트 입력용
3. 일정 흐름 유저 입력 받기
 - 드래그 앤 드랍(식당, 카페, 관광, 공원, 유원지,커스텀 등)
 - 시간 입력
 - 커스텀 입력의 경우 유저가 섭외지 테이블에 들어가는 데이터를 입력해야 섭외 과정을 진행

 - 임베딩 과정은 무료 모델과 유료모델 백엔드 개발자가 성능 비교했음
